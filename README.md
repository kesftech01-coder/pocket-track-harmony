# Pocket Track Pro

I need you to help me build a frontend for an MVP app called pocket track. There is a signing in page first which requires the Teachers name, class incharge of and the password. After signing or logging in, a screen containing every students details like; admission number, name , class, parent's phone number and the amount of pocket money the student has in total and the records of disbursments though out the term. Once the parent sends money to the teacher, using the phone number as linked to each student, the balance is updated on the students profile. During registartion of a new student , the teacher has to go to the administration pannel or page and enter any nessesary data like parents phone number, students admission number and name and class. This app reads M-Pesa massages  but does not touch the money. Any money sent to the teacher is safe and if the senders name and phone number is not in the records, then the app notifies the teacher for the correct placement of money.
